# Backend — Unit Converter

API em FastAPI responsável pela lógica de conversão de unidades.

## Estrutura

```
app/
├── main.py          # ponto de entrada
├── routers/         # rotas da API
├── services/         # lógica de conversão, isolada por gênero
├── schemas/         # modelos Pydantic (request/response)
├── core/            # constantes e configuração
└── tests/           # testes automatizados (Pytest)
```
